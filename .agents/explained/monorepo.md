# Echoray Monorepo Architecture

This document explains the architecture and configuration of the Echoray monorepo.

## Directory Structure

```
echoray-mono/
├── apps/
│   ├── web/                          # Main Next.js application
│   └── microapps/                    # Independent microapplications
│       ├── webscan/
│       ├── lead-ai/
│       └── [future-apps]/
├── packages/
│   ├── ui/                           # Shared UI component library (shadcn/ui)
│   ├── database/                     # Convex database layer
│   ├── config/                       # Shared TypeScript/ESLint configs
│   └── utils/                        # Shared utility functions
└── package.json                      # Root package.json (workspace config)
```

## Database Package (@echoray/database)

The `@echoray/database` package is the central database layer for the entire monorepo using Convex.

### Architecture

```
packages/database/
├── convex/
│   ├── _generated/           # Auto-generated by Convex CLI
│   │   ├── api.js            # Typed API references
│   │   ├── api.d.ts          # API type definitions
│   │   ├── dataModel.d.ts    # Document type definitions
│   │   └── server.d.ts       # Server utilities
│   ├── schema.ts             # Database schema definition
│   ├── users.ts              # User-related functions
│   ├── organizations.ts      # Organization functions
│   ├── members.ts            # Member management
│   ├── roles.ts              # Role & permission functions
│   ├── permissions.ts        # Bitwise permission system
│   ├── auth.ts               # Authentication helpers
│   └── [other-functions].ts  # Domain-specific functions
├── convex.json               # Convex configuration
├── package.json
└── tsconfig.json
```

### How It Works

1. **Single Source of Truth**: All Convex functions live in `packages/database/convex/`
2. **Generated Types**: Running `pnpm dev` in the database package generates TypeScript types
3. **Path Aliases**: Apps use `@convex/_generated/api` and `@convex/_generated/dataModel` to import typed references
4. **Shared Across Apps**: All microapps can import from `@echoray/database`

### Package Configuration

**packages/database/package.json:**
```json
{
  "name": "@echoray/database",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "exports": {
    ".": "./convex/_generated/api.js",
    "./api": "./convex/_generated/api.js",
    "./dataModel": "./convex/_generated/dataModel.js",
    "./server": "./convex/_generated/server.js",
    "./schema": "./convex/schema.ts",
    "./*": "./convex/*.ts"
  },
  "scripts": {
    "dev": "convex dev",
    "deploy": "convex deploy",
    "typecheck": "tsc --noEmit"
  }
}
```

**packages/database/convex.json:**
```json
{
  "functions": "convex/"
}
```

### Using the Database Package in Apps

**In apps/web/tsconfig.json:**
```json
{
  "compilerOptions": {
    "paths": {
      "@convex/*": ["../../packages/database/convex/*"]
    }
  }
}
```

**Import examples:**
```typescript
// Import typed API reference
import { api } from "@convex/_generated/api"

// Import type definitions
import type { Id, Doc } from "@convex/_generated/dataModel"

// Use in queries/mutations
const user = useQuery(api.users.currentUser)
const org = useQuery(api.organizations.getOrganization, { id: orgId })
```

### Running Convex Commands

```bash
# From root - run Convex dev for the database package
pnpm --filter @echoray/database dev

# Deploy to production
pnpm --filter @echoray/database deploy
```

### Environment Variables

Each app that uses the database needs:
```env
# In apps/web/.env.local
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
```

For backend functions, the database package needs (via Convex dashboard):
```env
GITHUB_BOT_TOKEN=ghp_xxx
RESEND_API_KEY=re_xxx
```

## UI Package (@echoray/ui)

The `@echoray/ui` package contains shared UI components using shadcn/ui and Tailwind CSS v4.

### Key Files

- `packages/ui/src/styles/globals.css` - Theme variables & design tokens
- `packages/ui/src/components/ui/` - shadcn/ui components
- `packages/ui/index.tsx` - Main exports

### Package Exports

```json
{
  "name": "@echoray/ui",
  "exports": {
    ".": "./index.tsx",
    "./components/ui/*": "./src/components/ui/*.tsx",
    "./lib/*": "./src/lib/*.ts",
    "./hooks/*": "./src/hooks/*.ts",
    "./styles/globals.css": "./src/styles/globals.css",
    "./src/styles/globals.css": "./src/styles/globals.css"
  }
}
```

### Using UI Components

```tsx
// From the UI package
import { Button } from "@echoray/ui/components/ui/button";
import { Sidebar, SidebarProvider, SidebarInset } from "@echoray/ui/components/ui/sidebar";
import { cn } from "@echoray/ui/lib/utils";

// Or via index export
import { Button, Accordion, Sidebar } from "@echoray/ui";
```

### App-Level CSS (apps/web/src/app/styles.css)

```css
@import "tailwindcss";
@import "@echoray/ui/styles/globals.css";

@source "../../../../packages/ui/src/**/*.{ts,tsx,js,jsx}";
```

### Adding New shadcn/ui Components

```bash
# Run from apps/web directory
pnpm dlx shadcn@latest add [component-name]

# Export from packages/ui/index.tsx
export * from "./src/components/ui/[component-name]";
```

## Common Issues

### Convex not connecting

1. Ensure `NEXT_PUBLIC_CONVEX_URL` is set in `apps/web/.env.local`
2. Run `pnpm --filter @echoray/database dev` to generate types
3. Check path alias `@convex/*` in tsconfig.json

### CSS Not Exported Error

Ensure both CSS paths are exported in UI package.json:
```json
"./styles/globals.css": "./src/styles/globals.css",
"./src/styles/globals.css": "./src/styles/globals.css"
```

### Styles Not Applied to UI Components

Add `@source` directive in app's styles.css pointing to the UI package.
