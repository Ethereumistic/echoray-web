#### Step 3.2: Extract Database Package (Convex)

**The `@echoray/database` package is the central database layer for the entire monorepo.**

##### Architecture Overview

```
packages/database/
├── convex/
│   ├── _generated/           # Auto-generated by Convex CLI
│   │   ├── api.js            # Typed API references
│   │   ├── api.d.ts          # API type definitions
│   │   ├── dataModel.d.ts    # Document type definitions
│   │   └── server.d.ts       # Server utilities
│   ├── schema.ts             # Database schema definition
│   ├── users.ts              # User-related functions
│   ├── organizations.ts      # Organization functions
│   ├── members.ts            # Member management
│   ├── roles.ts              # Role & permission functions
│   ├── permissions.ts        # Bitwise permission system
│   ├── auth.ts               # Authentication helpers
│   └── [other-functions].ts  # Domain-specific functions
├── convex.json               # Convex configuration
├── package.json
└── tsconfig.json
```

##### How It Works

1. **Single Source of Truth**: All Convex functions live in `packages/database/convex/`
2. **Generated Types**: Running `pnpm dev` in the database package generates TypeScript types
3. **Path Aliases**: Apps use `@convex/_generated/api` and `@convex/_generated/dataModel` to import typed references
4. **Shared Across Apps**: All microapps can import from `@echoray/database`

##### Package Configuration

**`packages/database/package.json`:**
```json
{
  "name": "@echoray/database",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "exports": {
    ".": "./convex/_generated/api.js",
    "./api": "./convex/_generated/api.js",
    "./dataModel": "./convex/_generated/dataModel.js",
    "./server": "./convex/_generated/server.js",
    "./schema": "./convex/schema.ts",
    "./*": "./convex/*.ts"
  },
  "scripts": {
    "dev": "convex dev",
    "deploy": "convex deploy",
    "typecheck": "tsc --noEmit"
  },
  "dependencies": {
    "@auth/core": "^0.37.4",
    "@convex-dev/auth": "^0.0.90",
    "@convex-dev/resend": "^0.2.3",
    "@octokit/rest": "^22.0.1",
    "convex": "^1.31.4",
    "resend": "^6.7.0"
  }
}
```

**`packages/database/convex.json`:**
```json
{
  "functions": "convex/"
}
```

##### Using the Database Package in Apps

**In `apps/web/tsconfig.json`:**
```json
{
  "compilerOptions": {
    "paths": {
      "@convex/*": ["../../packages/database/convex/*"]
    }
  }
}
```

**Import examples:**
```typescript
// Import typed API reference
import { api } from "@convex/_generated/api"

// Import type definitions
import type { Id, Doc } from "@convex/_generated/dataModel"

// Use in queries/mutations
const user = useQuery(api.users.currentUser)
const org = useQuery(api.organizations.getOrganization, { id: orgId })
```

##### Running Convex Commands

```bash
# From root - run Convex dev for the database package
cd packages/database && pnpm dev

# Or from anywhere using the workspace filter
pnpm --filter @echoray/database dev

# Deploy to production
pnpm --filter @echoray/database deploy
```

##### Environment Variables

The Convex deployment is configured via environment variables. Each app that uses the database needs:

```env
# In apps/web/.env.local
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
```

For backend functions, the database package needs:
```env
# In packages/database/.env.local (or via Convex dashboard)
GITHUB_BOT_TOKEN=ghp_xxx
RESEND_API_KEY=re_xxx
```

## Troubleshooting

### Issue: Module Resolution Errors

**Solution:** Ensure `tsconfig.json` paths are correctly mapped:
```json
{
  "compilerOptions": {
    "paths": {
      "@echoray/ui": ["../../packages/ui/src"],
      "@echoray/database": ["../../packages/database"],
      "@echoray/utils": ["../../packages/utils/src"]
    }
  }
}
```

### Issue: Cloudflare Deployment Fails

**Solution:** Check `wrangler.jsonc` configuration and build output directory:
```bash
# Verify build output exists
ls -la apps/web/.vercel/output/static

# Check wrangler config
cat apps/web/wrangler.jsonc
```

### Issue: Convex not connecting

**Solution:** Ensure Convex is configured correctly:
```bash
# Run Convex dev from the database package
cd packages/database
pnpm dev

# This generates types and syncs with your Convex deployment
```

Check that:
1. `NEXT_PUBLIC_CONVEX_URL` is set in `apps/web/.env.local`
2. Path alias `@convex/*` points to `../../packages/database/convex/*` in tsconfig.json
3. The database package has `convex.json` with `"functions": "convex/"`

### Issue: PNPM workspace not resolving packages

**Solution:** 
1. Delete all node_modules: `pnpm clean`
2. Delete pnpm-lock.yaml
3. Reinstall: `pnpm install`
